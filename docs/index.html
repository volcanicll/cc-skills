技能分类

四个方向，十种能力

每个技能是一个独立文件夹：SKILL.md 指令 + 可选脚本、文档与测试。Claude 根据上下文自动激活对应技能；其中 browser-login-session 是新建 skill 的结构模板（元 skill）。

创意设计 3
naive-doodle-avatar 将真人肖像照片转为可爱的手绘 chibi 涂鸦头像，保留发型、眼镜等识别特征
image-to-hand-drawn 将整张照片转换为高质量手绘插图，保留完整场景元素
photo-to-editorial-poster 将照片转为编辑风海报：上半部精修调色，下半部手绘插画
开发工具 4
browser-login-session （元 skill 模板） 通过 CDP 复用浏览器已登录态：提取指定域名 Cookie/Token 并组装 API 请求头，纯 Python 标准库
git-history-cleaner 清理 Git 仓库历史中的大文件，使用 git-filter-repo 重写历史并压缩仓库体积
changelog-writer 将 Git 提交记录整理为面向用户的 Release Notes 与 CHANGELOG 条目
swagger-docs 将 Swagger/OpenAPI 接口文档同步为本地离线缓存，支持按路径/关键字/标签/权限编码查询接口与 schema
rdc-work-items 研发云工作项月度工作量自动化：从 git 提交统计生成工作量 Excel，完成工作项导入、导出与接口状态流转，纯 Python 标准库零依赖
学习教育 2
eli5 用超级通俗的方式解释任何主题、代码或系统，并生成漂亮的 HTML 可视化页面
exam-learning-assistant 考试练习自动化助手，支持多种学习模式、错题复盘、考试报告生成
元工具 1
skill-manager Agent Skills 包管理器，支持从远程 Git 注册表列出、安装、更新技能
安装方式

两种安装方式

推荐通过 Claude Code Marketplace 安装，按需选择分类插件。

Marketplace 安装

/plugin marketplace add volcanicll/cc-skills

添加后运行 /plugin marketplace，选择 volcanic-skills 并安装需要的分类插件。

直接安装

/plugin install creative-tools@volcanic-skills

也可以一次安装全部四个分类插件（开发工具已包含 swagger-docs 与 rdc-work-items），或手动 clone 仓库复制技能文件夹。

# 学习模式说明

本技能支持两种模式，根据使用场景自动切换。

---

## 模式1: 考试辅助模式 (Exam Mode)

### 触发条件
- 用户正在参加在线认证考试
- 需要实时答题辅助
- 时间压力较大

### 工作流程
```mermaid
graph LR
    A[连接浏览器] --> B[识别题目]
    B --> C[查询题库]
    C --> D[显示答案]
    D --> E[自动选择]
    E --> F[下一题]
    F --> B
```

### 特点
- ⚡ 快速响应
- 🎯 直接给答案
- 🤖 自动化操作
- 📊 实时进度显示

### 使用方法
```
"帮我做这个HarmonyOS考试"
"连接浏览器开始答题"
"继续下一题"
```

### 输出示例
```
第5题: 判断题
题目: 元服务需要显式安装后才能使用
答案: ✗ 错误
解析: 元服务的核心特性是"免安装"
[已自动选择"错误"并点击下一题]
```

---

## 模式2: 自主学习模式 (Learning Mode)

### 触发条件
- 用户练习做题
- 需要理解知识点
- 积累错题

### 工作流程
```mermaid
graph LR
    A[识别题目] --> B[查询题库]
    B --> C[显示答案]
    C --> D[显示解析]
    D --> E[标记重点]
    E --> F[添加到错题本]
```

### 特点
- 📝 详细解析
- 📚 知识点关联
- 🎓 错题记录
- 💡 学习建议

### 使用方法
```
"练习模式：这道题怎么做？"
"解释一下为什么选C"
"把这道题加入错题本"
"生成复习单"
```

### 输出示例
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第12题: 单选题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

题目: 命名空间的命名规范是？
A. 小驼峰
B. 大驼峰
C. 下划线
D. 无限制

✅ 正确答案: B. 大驼峰 (PascalCase)

📖 解析:
  ArkTS遵循TypeScript命名规范，命名空间
  使用PascalCase（大驼峰）命名。

🔗 相关知识点:
  - 类名: PascalCase
  - 变量名: camelCase
  - 常量: UPPER_SNAKE_CASE

💡 记忆技巧:
  "NameSpace" = "NS" = "New Style" = "大写开头"

[已添加到今日错题本]
```

---

## 自动模式切换

技能会根据上下文自动判断模式：

| 场景 | 模式 | 判断依据 |
|------|------|----------|
| "考试"、"认证" | 考试辅助 | URL包含exam/certification |
| "练习"、"学习" | 自主学习 | 用户明确说明 |
| "解释"、"为什么" | 自主学习 | 需要解析 |
| "继续"、"下一题" | 保持当前模式 | 延续之前状态 |

---

## 答疑交互

### 当不确定答案时
```
⚠️  题库中未找到匹配题目

题目: [题目内容]
可能的答案:
  1. A (相似度: 60%)
  2. B (相似度: 40%)

请选择或输入正确答案
```

### 确认机制
```
✅ 已选择: C. onBackground()

是否确认? [Enter=确认 / n=重新选择]
```

### 纠错学习
```
用户提供答案: B
正确答案: C

📚 已记录:
  - 原因: 混淆了onBackground()和onForeground()
  - 重点: onBackground()在UI不可见时调用
  - 已加入复习队列
```
